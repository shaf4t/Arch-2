# Arch 2 - Hogeschool Rotterdam

Oefeningen en opdrachten voor Arch 2 aan de Hogeschool Rotterdam.

## Weekindeling

Elke lesweek krijgt een eigen map:

```text
Week 5/
Week 6/
Week 7/
```

De bestaande Python-bestanden zijn per week georganiseerd. Nieuwe weken kunnen
worden toegevoegd zonder de eerdere oefeningen te wijzigen.

## Bestanden uitvoeren

De opdrachten zijn losse Python-programma's. Voer een bestand bijvoorbeeld uit
met:

```powershell
python "Week 7\A2W7P2.py"
```
